## 기술 개요

- **텍스트 시스템**: 폰트 2종 + 코드 스트림 (사전 렌더 그래픽이 아님)
  - 16×16 폰트(한자·카나·ASCII 405자) — 메뉴/헤더/메시지, 코드 `0x200 + 4k`
  - 8×8 폰트(ASCII·반각 카나 155자) — 유닛명/무기명/숫자
- **한글화 방식**: 렌더러 훅 없이 **폰트 뱅크 교체 + 코드 재작성**
  - 롬 512KB → 1MB 확장 후 폰트 뱅크 재배치, 폰트 참조 8곳 패치
  - 한글 글리프: GulimChe 16px(16×16), Galmuri7 8px(8×8)
  - 8×8은 카나 슬롯 82칸을 한글로 전환 (소문자는 맵 이름용으로 보존)
